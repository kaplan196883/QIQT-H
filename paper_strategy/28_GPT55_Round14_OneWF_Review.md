Better description: **"ψ-monist quantum mechanics with an additional finite-information axiom constraining physically instantiated universal states."** Not ψ-supplemented ontologically, but **ψ-constrained or ψ-restricted**.

> "But rejecting measurement independence remains a serious move. Bell's measurement-independence assumption is not refuted merely by saying that the apparatus and environment have physical states. To reject measurement independence, the framework needs a specific account of why the source variables and later measurement settings are statistically correlated in just the right way."

## (f) THE CENTRAL REMAINING TENSION — MWI-without-many-worlds

> "Universal-wave-function monism plus unitary evolution plus decoherence is structurally very close to Everett/MWI."

After decoherence and FQ-strict orthogonalization:
$$\rho_A = |\alpha|^2 |A_0\rangle\langle A_0| + |\beta|^2 |A_1\rangle\langle A_1|$$

**This is not yet a single outcome.** It is a classical mixture over multiple possible records. To get one actual record per run, one still needs either:

1. An objective collapse/selection rule
2. An additional modal rule saying which diagonal component is actual
3. An Everettian reading where all branches are real
4. **A new theorem showing that FQ itself forbids multiple coexisting macroscopic records**

> "Without such a theorem, the framework risks being 'Everett without saying worlds.' In fact, if FQ makes decohered branches exactly noninteracting, it may strengthen the Everettian branch structure rather than eliminate it."

**Substantively different from MWI only if FQ genuinely derives single-outcome ontology. That remains open.**

## (i) 12 remaining issues identified

1. **Precise definition of FQ** — algorithmic info, operational distinguishability, entropy, state-counting, trace distance, or something else?
2. **Entropy does not automatically imply finite wave-function precision**
3. **Precision floor needs a metric** — $\epsilon(R) > 0$ requires specified state-space metric
4. **Dynamics under FQ** — does Schrödinger preserve FQ-allowed class?
5. **Basis problem for thresholding** — in which basis are small off-diagonal terms set to zero?
6. **Improper vs proper mixtures** — decoherence gives reduced improper mixtures; exact diagonality doesn't by itself select one outcome
7. **Single-outcome problem (CENTRAL)** — universal WF evolving unitarily normally contains all decohered branches; FQ must explain why only one macroscopic record is physically actual
8. **Born rule** — Born-typicality theorem still needed; in ψ-only ontology, what is typicality measure over (wave functions, histories, branches, records, or initial conditions)?
9. **Bell measurement-dependence** — explicit non-conspiratorial model needed
10. **Relation to MWI** — if all decohered branches remain, theory is Everettian in structure; if only one branch remains, framework needs collapse or selection mechanism
11. **Universal wave function vs AQFT language** — AQFT is in terms of states on algebras, not necessarily literal universal WF; bridge needs explicit formulation
12. **"Different actual universes" language is problematic** — if multiple runs happen sequentially in same universe, there is ONE universal wave function containing all runs; the "ensemble over different universes" phrasing needs clarification

## The critical new finding: issue #12

GPT-5.5 raises a crucial point not previously identified:

> "If the ensemble is over different possible or actual universes, the probability interpretation needs clarification. **If repeated lab runs occur inside one universe, then there is one universal wave function containing all runs.**"

This is a real terminological issue. Multiple runs of a double-slit experiment happen *sequentially in the same universe*. They're not different universes. So saying "different runs correspond to different actual physical universes" is wrong.

The right framing: different runs are *different sequential events in the same universe*, each with different actual physical conditions (different particles emitted by the source, different microstates of apparatus + environment AT THAT MOMENT, different environmental fluctuations during that specific run).

This needs to be fixed in the papers.
