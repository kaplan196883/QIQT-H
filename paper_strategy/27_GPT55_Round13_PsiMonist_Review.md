## The key distinction GPT-5.5 makes

Two **orthogonal** axes that were being conflated:

| Axis | Meaning | Framework's position |
|---|---|---|
| **Monism vs dual ontology** | Kind of ontology (one thing or multiple) | **Monist** — only the wave function |
| **Hidden-variable / supplementation status** | Whether textbook state is *complete* | **Formal-ψ-incomplete** — per-run state has structure not in formal state |

The framework is **both** ψ-monist AND formal-ψ-incomplete. These don't conflict.

## (a) ψ-monism vs hidden variables — substantive vs terminological

**Substantively rejects:**
- Bohmian-style implication of second physical layer
- Particle-supplementation, extra fields, primitive ontology
- "Wave function plus extra stuff" reading
- Guidance equation between layers

**Does NOT reject:**
- The broader Spekkens-style classification: if textbook formal state corresponds to many possible per-run wave functions, the formal state is not ontically complete; in foundations taxonomy, this is "ontic supplementation" even if the supplementing material is itself wavefunction-like

> "Not hidden variables in the narrow Bohmian sense. Yes hidden variables / ontic-state supplementation in the broad foundations sense. Better phrase: **wavefunction-valued ontic completion** or **formal-ψ-incomplete ψ-monism**."

## (b) Pure-state extremality problem — important technical point

> "If a preparation truly has the pure density matrix $\rho = |\psi\rangle\langle\psi|$, then any ensemble decomposition reproducing exactly the same predictions for all observables must be trivial: all elements of the ensemble are the same ray $|\psi\rangle$ up to phase."

If the framework says textbook pure state corresponds to a nontrivial distribution of distinct per-run wave functions, **must specify one of four escapes:**

1. The textbook state is only a coarse-grained state over a restricted observable algebra
2. The per-run differences are below physical resolution and operationally inaccessible because of FQ
3. The formal state is not really a pure physical state, but an idealized ensemble label
4. The claim applies only after decoherence has produced macroscopic record sectors

**Without one of these, the proposal conflicts with the extremality of pure quantum states.**

The most plausible escape for QIQT-H is **(4)**: the formal/per-run distinction applies to decohered macroscopic record sectors, not arbitrary pure microscopic states.

## (c) Classical stat mech analogy — legitimate only after FQ-decoherence

> "The analogy is legitimate for FQ-decohered macroscopic records. It is not legitimate for general microscopic coherent superpositions unless further structure is supplied."

Microscopic superposition $\alpha|0\rangle + \beta|1\rangle$ is NOT analogous to temperature — has phase coherence with interference consequences. Treating as ignorance mixture gives empirically different predictions.

**The analogy works for:** post-decoherence + FQ macroscopic record sectors (strict classical mixture)
**The analogy fails for:** arbitrary pure coherent superpositions

The framework should be careful about this. The temperature analogy applies *after* decoherence + FQ produces strict mixture; it does NOT justify treating all formal states as ensembles.

## (d) Versus Ballentine

> "It is close to Ballentine, but not identical."

**Genuine novelty over Ballentine:**
1. Per-run wave function as actual physical state
2. (FQ) finite physical specification precision
3. Decoherence + FQ → physically zero (strict classical mixture)
4. Branch definiteness per run
5. Holographic/nonseparable motivation (especially for Bell)
6. Typicality program for Born statistics

> "If these additions are formalized, framework is not merely Ballentine but a wavefunction-monist ontological completion of the ensemble interpretation. But if additions remain only qualitative, skeptical readers will reasonably say: 'This is Ballentine + decoherence + speculative holographic language, without yet a worked model.' The genuine novelty is the proposed mechanism turning improper decohered mixtures into strict classical mixtures via FQ. That is the part that needs the most mathematical development."

## (e) Terminology pushback — partially defensible

**Defensible to reject:** Bohmian hidden variables, particle hidden variables, second-ontology hidden variables, "wave function plus extra stuff."

**NOT defensible to reject:** the broad ontological-models classification, if the framework says the textbook formal wave function does not specify the actual per-run state.

**Best framing for the papers:**
> "QIQT-H is ψ-monist and ψ-ontic. It contains no non-wavefunction ontology. However, relative to the textbook formal wave function, it is formal-ψ-incomplete: the actual ontic state is the per-run finite-precision wave function. Thus, in the broad ontological-models taxonomy, it may be represented by hidden wavefunction-valued ontic states."

**This avoids a terminology fight with foundations readers.** Simply rejecting "hidden variables in the broad sense" will be seen as disagreement about labels rather than substantive technical distinction.

## (f) PBR — avoided

> "If the framework is genuinely ψ-ontic at the per-run level, then PBR is not a problem."

PBR rules out ψ-epistemic models where distinct quantum states overlap in ontic support. QIQT-H says distinct formal wave functions correspond to **non-overlapping** equivalence classes of per-run wave functions:
$$\Lambda_\psi \cap \Lambda_\phi = \varnothing \text{ for } \psi \ne \phi$$

Framework is ψ-ontic in PBR/Harrigan-Spekkens sense. PBR avoided either by:
1. Disjoint supports (ψ-ontic)
2. Failure of preparation independence (holographic nonseparability)

**Caveat:** if finite precision makes nearby formal states physically indistinguishable, framework must define what counts as a distinct formal state. PBR applies to operationally distinct preparations.

## (g) Bell — unchanged by ψ-monism

> "The fact that the hidden structure is wavefunction-like rather than particle-like does not change the Bell analysis."

Bell doesn't care what kind of thing λ is. The framework rejects measurement independence $\rho(\lambda|a,b) \ne \rho(\lambda)$ via holographic nonseparability. Same escape as before, with $\lambda = \Psi_{\rm run}$ rather than particle positions.

Still owes:
1. How setting correlations arise holographically
2. Why they don't permit operational signaling
3. How they reproduce quantum CHSH value
4. Why they aren't eliminable by cosmic/delayed-choice settings
5. Whether retrocausal, superdeterministic, globally constrained, etc.

## (h) Honest one-paragraph assessment

> "With the ψ-monist framing made explicit, QIQT-H is cleaner and less vulnerable to the charge that it secretly adds Bohmian particles or a second ontology. Its best description is: **a ψ-ontic, wavefunction-only, formal-ψ-incomplete ensemble interpretation in which the textbook wave function is a coarse-grained descriptor of many possible finite-precision per-run universal wave functions**. Decoherence plus FQ is then supposed to turn macroscopic record superpositions into strict classical mixtures, with each run occupying one branch. That is coherent as a foundations program, but it remains an ontological completion relative to textbook QM: the per-run wave function carries physical information not specified by the formal state. Therefore the author's pushback is substantive against Bohmian/dual-ontology comparisons, but mostly terminological against the broad Spekkens-style 'hidden-variable' classification."

## (i) arXiv suitability — close, one more clarification needed

**Required addition:** explicit ontological-model dictionary, with single key sentence:

> "QIQT-H contains no non-wavefunction ontology. Nevertheless, in the broad ontological-models sense, the per-run finite-precision wave function plays the role of the ontic state $\lambda$, while the textbook formal wave function labels an ensemble over such states. Thus the theory is **ψ-monist but formal-ψ-incomplete**."

**Other clarifications needed:**
1. Whether $\Psi_{\rm formal}$ is ever an actual individual state or always an ensemble descriptor
2. Whether microscopic coherent superpositions remain physically real per-run wave functions
3. That the temperature analogy applies safely only to decohered macroscopic mixtures
4. How FQ turns improper mixtures into strict mixtures on the relevant algebra
5. What the Born/typicality assumption is
6. How the framework wants to be classified terminologically

> "If the paper simply rejects the 'hidden variables in the broad sense' label without explaining the taxonomy, foundations readers will likely view that as a disagreement about labels rather than a substantive technical distinction."
